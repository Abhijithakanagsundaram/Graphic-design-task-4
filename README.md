# How AI Works – Infographic Design Project

## Overview
This project is an infographic created to visually explain how Artificial Intelligence (AI) works. The infographic simplifies complex AI concepts into an easy-to-understand visual format using icons, charts, illustrations, and structured information design.

## Features
- Visual explanation of AI workflow
- Modern and professional infographic design
- Use of icons and illustrations
- AI adoption chart visualization
- Clear information hierarchy
- Technology-themed layout and styling

## Topics Covered
- Data Collection
- Training
- Processing
- Decision Making
- Improvement

## Tools Used
- Canva
- Infographic Design Elements
- Icons and Charts

## Learning Outcome
Through this project, I learned:
- Data visualization techniques
- Information design principles
- Visual storytelling
- Layout balancing and typography
- Creating professional infographic designs

## Project Output
The final output was exported in:
- PNG format
- PDF format
